일괄 해결은 카드의 결정대로 필요한 파일만 파이프라인(판독·등록 → 추출 → 추출 검증 → 요약 생성 → 요약 품질 검증 → DB 동기화 → 카탈로그 재생성)에 태워 순서대로 처리합니다. 새 PDF는 등록 단계에서 한 번 판독(LLM 1회)합니다. 중간에 문제가 생긴 파일은 빼고 나머지는 끝까지 진행한 뒤, 남은 문제를 다시 카드로 띄웁니다 — 목차 대응이 성립하지 않은 문서는 플랫으로 수용할지 묻는 카드로 돌아옵니다.
